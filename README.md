# Sorrento Meeting 2027

Website for the Sorrento Meeting, 21–24 March 2027, Grand Hotel Vesuvio.

Published at <https://lawrennd.github.io/sorrento2027/> once GitHub Pages is enabled (source: GitHub Actions).

This year site uses the shared remote theme [`lawrennd/jekyll-theme`](https://github.com/lawrennd/jekyll-theme) with `style: sorrento`. Programme posts can be edited through giki edit links or the Decap admin at `/admin/`.

See `doc/` for organiser notes.
